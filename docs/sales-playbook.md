# Sales Playbook — WA Admin AI

Panduan praktis dari "produk siap" → "client pertama bayar".

## 🎯 Target client (urut prioritas)

Pilih industri yang **rame chat WA tapi adminnya overload**:

| Industri | Kenapa cocok | Cara cari prospek |
|---|---|---|
| 🏥 **Klinik gigi/skincare** | Booking & FAQ berulang | Google Maps area Anda, IG @klinikgigi_kota |
| 💇 **Salon/barbershop premium** | Janjian appointment + tanya harga | IG salon area Anda, Tiktok local |
| 🧺 **Laundry kiloan** | Status order, pickup, harga | Google Maps "laundry kiloan [kota]" |
| ☕ **Cafe yg jual delivery** | Menu, jam, pesan delivery | GoFood/GrabFood top resto area Anda |
| 🚗 **Dealer motor/mobil** | Simulasi cicilan, test ride | IG dealer resmi area Anda |
| 🏪 **Toko online IG/Shopee** | "Ready stock?", "Berapa?", "Lokasi?" | IG dengan 5-50rb followers |

**Sweet spot**: bisnis yang sudah ada **>50 chat/hari** dan punya minimal **1 admin manusia** yang kewalahan.

## 🎬 Demo script (15 menit, video call atau ketemu langsung)

### Menit 0-2: Pain discovery
- "Kak biasanya berapa chat WA masuk per hari?"
- "Pertanyaan apa yang **paling sering** ditanya customer?"
- "Pernah ngga customer hilang gara-gara balas lama?"

→ **Tujuan**: bikin mereka sadari nyeri sendiri, bukan Anda ceramah.

### Menit 2-7: Live demo
1. Buka https://yourapp.com/demo
2. Pilih industri yang **mirip bisnis mereka**
3. Tunjukkan knowledge base preset
4. Suruh **mereka** ketik pertanyaan customer real (jangan Anda yang ketik)
5. AI jawab → kasih waktu mereka baca, expressikan: "Lihat, ini balasannya seperti admin Kak"

### Menit 7-10: "Bayangkan ini bisnis Kak..."
1. Login ke dashboard Anda (workspace "Demo Klinik" dummy)
2. Tunjukkan: tambah Knowledge → "Misal nanti Kak isi sini menu salon, harga, jam..."
3. Tunjukkan Inbox → "Semua chat di sini, Kak bisa lihat & ambil alih kapan saja"
4. Tunjukkan toggle AI on/off → "Kalau Kak mau libur, AI tetap balas. Kalau Kak balas sendiri, AI berhenti"

### Menit 10-13: Address objection
Umum:
- "Nanti customer ngga ngerasa bot ya?" → "AI kami pakai persona Anda. Banyak customer ngga sadar."
- "Nanti nomor saya kena banned?" → "Ngga, kami pakai WhatsApp Cloud API resmi Meta — bukan bot unofficial."
- "Kalau AI salah jawab gimana?" → "AI hanya jawab dari knowledge yang Kak isi. Kalau ragu, AI bilang akan dihubungkan ke admin."
- "Harganya mahal." → "Kak bayar 399rb/bln. Kalau 1 customer ngga hilang = balik modal."

### Menit 13-15: Close
- "Boleh kita coba 14 hari gratis dulu? Saya bantu setup-in sekarang, langsung jadi 30 menit."
- Kalau ragu: "Kasih saya 1 hari, saya setup-in pakai data bisnis Kak, Kak tinggal lihat hasilnya."

## 📝 Onboarding client baru (checklist)

Setelah deal:

- [ ] Buat workspace di dashboard
- [ ] Invite owner sebagai admin
- [ ] **Bantu client buat Meta App** (mereka login akun FB sendiri — biar tidak kena Anda)
   - Buat Meta App → tambah produk WhatsApp → ambil Phone Number ID + Access Token
   - **Use System User token** (permanent, bukan 24 jam)
- [ ] Connect WhatsApp di dashboard mereka
- [ ] Setup webhook di Meta (Anda kasih URL ngrok dev / URL production)
- [ ] **Isi minimal 10 knowledge base entries** dari data mereka (jam buka, harga, layanan, FAQ umum)
- [ ] Edit System Prompt (persona AI sesuai brand mereka)
- [ ] Kirim WA test dari nomor sendiri → cek AI jawab benar
- [ ] Aktifkan AI auto-reply
- [ ] Schedule follow-up 3 hari kemudian — minta feedback

## 🚀 Roadmap pasca 5 client pertama

**Setelah 5 client paid**:
1. Deploy ke production (VPS/Railway) → tidak bisa lagi pakai laptop pribadi
2. Beli domain & HTTPS (Rp 150rb/tahun)
3. Setup Midtrans subscription → auto-debit bulanan
4. Bikin **affiliate program** — client dapat 20% dari referral (banyak salon punya WA group sesama owner)
5. Naikkan harga ke normal untuk client ke-6+
6. Hire 1 freelance untuk **bantu setup client baru** (Anda fokus jualan)

---

## ⚠️ Pitfalls yang harus dihindari

1. **Jangan ngotot pakai akun FB Anda** untuk Cloud API → minta client pakai akun mereka
2. **Jangan kasih trial terlalu lama** (14 hari max) → bikin urgency
3. **Jangan jualan tanpa demo dulu** → conversion turun 80%
4. **Jangan janji "AI bisa segalanya"** → bilang AI bisa handle 70-80% pertanyaan, sisanya admin
5. **Jangan lupa minta testimoni** dari client puas (dipakai untuk closing client berikutnya)
